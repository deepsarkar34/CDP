# CDP Journey Demo

An interactive, presenter-driven demo that explains how a customer data platform (CDP) works, by following one HCP (Dr. Brown) from raw source systems to live channels:

Hook → Capture → Clean → Master → Resolve → Segment → Activate

Vendor-neutral by default, with a toggle for Salesforce Data 360, Adobe Real-Time CDP and a composable Databricks stack.

Status: design in progress (see `docs/spec.md` once written). All people, IDs and counts are illustrative.
